# Documentation

This directory is the canonical home for human-facing Bookshelf documentation.

Use it for:

- architecture overviews
- deployment and operations guidance
- API references
- architecture decision records

The `spec/` directory remains available for planning, staged implementation notes,
and spec-driven development artifacts. If a document is meant to help contributors,
operators, or reviewers understand the current system, it belongs under `docs/`.
